# Admin Dashboard

An admin dashboard layout built as part of The Odin Project's Intermediate HTML and CSS course.

## Overview

The goal of this project was to build a complex dashboard interface using CSS Grid while combining Grid and Flexbox to create a clean, structured layout. The design was based on the reference provided by The Odin Project.

## Features

- CSS Grid-based page layout
- Sidebar navigation
- Header with search and profile sections
- Project card layout
- Dashboard widgets
- Reusable colour palette using CSS custom properties

## Built With

- HTML5
- CSS3
- CSS Grid
- Flexbox

## What I Learned

This project helped me become more comfortable with:

- Building layouts with CSS Grid
- Combining CSS Grid and Flexbox effectively
- Structuring larger CSS files
- Using CSS custom properties for consistent styling
